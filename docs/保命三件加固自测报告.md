## 三、遗留问题与风险提示

1. **`limit` 上限 100 的取舍**：`/api/meds`、`/api/news` 等商品/资讯类接口若单页需要超过 100 条，必须依赖翻页；前端已全部按 20 条 + 加载更多实现，符合现状。
2. **`/api/chats` 仍忽略 `status` 参数**：MyChats.vue 的 tab 过滤依旧在前端本地完成，因此「某状态恰好落在未拉取分页之外」时该 tab 会为空，需要继续点「加载更多」才会出现；如需彻底正确，需后端 `/api/chats` 支持 status 过滤（本次未改动筛选语义）。
3. **`/api/orders` 等列表接口的 `total` 是实时 `COUNT(*)`**：高频翻页会多一次 COUNT 查询；当前数据量（订单 30、消息 85 量级）无性能压力，量大后可考虑缓存或游标分页。
4. **`BEGIN IMMEDIATE` 在 SQLite 单文件下会短暂串行化写入**：并发写更安全，但极端并发下可能出现 `database is locked`（已设 `timeout=15` 兜底）；PG 部署不受影响。
5. **`.env` 中的 `JWT_SECRET` 为本机生成值**：换机器或重新部署需重新生成（`python -c "import secrets;print(secrets.token_hex(32))"`），否则会导致旧 token 失效；`.env` 已被 `.gitignore` 忽略，不会进版本库。
6. **测试数据污染**：自测真实下单/支付在 `bailing.db` 中留下若干条测试订单（如 order_id 37/38/39/40，状态 待发货/已完成）与对应通知，如需干净演示数据可清理这几条。
7. **`/api/health` 的 `llm_last` 依赖外部模型网关**：本轮探测正常（`ok=true`），但此前曾出现 `HTTP 403 Forbidden`；该项属于外部依赖，非本次加固范围。
